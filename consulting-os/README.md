# Consulting OS

A founder-led firm usually has an org chart and a Slack channel. What it doesn't have is an operating system.

Work arrives as pings. Marketing is Sunday night. Pipeline is whoever remembered to follow up. The founder is still the router: every draft, every list, every "should we?" lands on the same desk.

Consulting OS is that firm, installed as software.

Three functions every organization actually needs — **how we run**, **how we speak**, **how we find work** — each owned by a specialist agent. A coordinator agent orchestrates them in a hub-and-spoke topology. Human-in-the-loop is the control plane: nothing posts, nothing sends, nothing becomes a worked list until a person says so.

Audit → Install → Operate. That's the offer. This folder is the OS you'd be installing.

Live firm: [jamesbarfordai.com](https://jamesbarfordai.com)

## The three engines

**[Org engine](org-engine/)** — The operating cadence. A chief-of-staff coordinator sits at the hub. Specialists report in. Quality gates fire on a clock. The principal gets one packet, not a stream.

**[Marketing engine](marketing-engine/)** — The voice of the firm, on a rhythm. Drafts land in a weekly packet. The principal pastes. The engine never publishes. Usefulness is the bar, not volume.

**[GTM Spartan](gtm-spartan/)** — Hunt, list, apply. The go-to-market loop as three stations behind one adapter contract. Score a fit, draft the outreach, queue it. A human still clicks send.

That's an AI operating system with the key functions of an organization — not a chatbot with a to-do list.
