# Consulting OS

The consulting practice as an operating system. Three engines cover how the firm runs, how it speaks, and how it finds work. A coordinator agent runs them hub-and-spoke. A person signs off before anything posts, sends, or becomes a worked list.

Audit → Install → Operate. That's the offer. This folder is the OS you'd be installing.

Live firm: [jamesbarfordai.com](https://jamesbarfordai.com)

## The three engines

**[Org engine](org-engine/)** — Coordinator at the hub. Specialists report in. The principal gets one packet, not a stream.

**[Marketing engine](marketing-engine/)** — Weekly drafts in the firm's voice. The principal pastes. The engine never publishes.

**[GTM Spartan](gtm-spartan/)** — Hunt, list, apply. Score a fit, draft the outreach, queue it. A human still clicks send.
