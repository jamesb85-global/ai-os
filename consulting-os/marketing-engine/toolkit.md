# Toolkit shape

A content pass produces a packet, not a feed.

## Packet

Each Sunday packet has two drafts. Each draft has:

- Hook (one line)
- Body (short, honest, no cheerleading)
- Close (optional CTA; never a pitch deck dump)
- Source note (what this is based on — a week in ops, a pattern, a question)

## Usefulness bar

Would a founder-operator do something different this week after reading this? If not, rewrite.

## Surfaces

Primary paste surface is LinkedIn. Site copy lives on [jamesbarfordai.com](https://jamesbarfordai.com). This engine does not publish the site.
