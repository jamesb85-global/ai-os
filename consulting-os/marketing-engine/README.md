# Marketing engine

The organization's **how we speak** function. A specialist agent on a spoke, reporting to the coordinator, producing a packet on a clock. It doesn't run a feed. It doesn't publish. The principal pastes.

## How it works

Sunday, two drafts. Each one has a hook, a body, a close, and a source. The usefulness bar: would a founder-operator do something different this week after reading this? If not, it gets rewritten before it reaches the packet.

Tuesday and Thursday, a reminder to paste. The coordinator gates content quality on Sunday.

## What the agent does

It writes in a founder-led voice. Short. Honest. No cheerleading. It doesn't name a client industry as the firm's identity. It doesn't invent case studies. Vertical-only copy stays in the buyer's room.

Primary surface is LinkedIn, as a paste. Site copy lives on [jamesbarfordai.com](https://jamesbarfordai.com). This engine doesn't ship the website.
