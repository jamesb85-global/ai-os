# A run

The loop on a sample week. No live names.

**Hunt** returns three cards. A 12-person services firm where the founder is still the routing layer — fit. An inbound that only says "we want a weekly packet" — skip. A referral that wants drafts, not a robot on LinkedIn — keep.

**Human gate.** Keep the services firm. Keep the drafts-only seat. Skip the vague inbound. Then list can run.

**List** writes two rows into one working file. Prep notes: headcount, founder still acting as chief of staff, content seat that must not auto-post. No email addresses in git.

**Apply** drafts one application into the queue. Their pain in the first line. The install in one sentence. The ask is a call. Submit is still a click.
