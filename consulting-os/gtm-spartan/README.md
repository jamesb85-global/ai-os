# GTM Spartan

Hunt → list → apply. Vendor APIs only. A human still clicks send.

This is an adapter interface and a canned fictional run. It is not a scraper. It does not submit. It does not hold marketplace cookies.

## Stations

| Station | Job |
|---|---|
| Hunt | Cards and patterns. No named lists. James marks keep/skip |
| List | Candidate prep after keep. One live working file, not a dump into git |
| Apply | Drafts for a board. Human submits |
