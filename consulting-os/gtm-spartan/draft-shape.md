# Spartan draft shape

Drafts a human pastes. Never submit.

## Shape

1. **First line** — the pain they wrote, in their words.
2. **What I'd install** — Audit → Install → Operate, one sentence.
3. **Proof of method** — how the OS runs, not a named client.
4. **Ask** — a short call, not a proposal dump.

## Rules

- Identity line verbatim when it appears: "I run operations inside founder-led firms and build the AI systems that run them."
- Credential: Claude Certified Architect. Write it verbatim.
- No cheerleading. No negative framing.
- No auto-send. Queue only. Human clicks.

Live board adapters stay private. This folder holds the shape.
