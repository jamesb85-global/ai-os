# Draft shape

Apply is a generation station with a contract, not "write something good."

The Spartan draft has four moves, in order:

1. **Their words** — the pain they wrote, not a rewritten version that sounds like us.
2. **The install** — Audit → Install → Operate, one sentence. What would actually land on their desk.
3. **The method** — how the OS runs. Not a named client. Not a case study the model invented.
4. **The ask** — a short call. Not a proposal.

The draft is queued. **Human-in-the-loop** owns submit. No auto-send, no "I'll just hit the API." That's the difference between an application system and a spam cannon.

Voice matches the firm: short, honest, no cheerleading, no negative framing. Identity belongs on the site and in the principal's mouth, not as a stamp the generator slaps on every closer.

Same shape behind every apply adapter. The board can change. The contract doesn't.
