# Seller Origination

**Absorbs:** Public license rosters, review velocity, succession flags → a ranked call list, refreshed on a cadence.

**Stays human:** Who is actually HOT. Verify flags. Who you want as a client.

**In:** Territory sources (license file, public reviews). Exclusion list for names already in pipeline.

**Out:** Ranked table. Call-first / watch / succession / verify.

**Install:** Swap the state source and CRM. Territory files do not travel. Demo uses fictional rows.
