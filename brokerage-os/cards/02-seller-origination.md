# Seller Origination

Turns public information into a ranked call list the broker can grade.

## What the agent does

It reads the territory: license-year band, solo vs group, review velocity, a successor already on the masthead. Then it ranks: call first, watch, or succession already underway. Verify when the signal is noisy.

The list refreshes on a cadence. Names already in the pipeline stay off it.

## Human in the loop

The list is a suggestion. Who is worth calling is the broker. The agent doesn't dial. It doesn't decide hot.
