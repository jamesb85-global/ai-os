# The fulfillment engine

One file moving through a practice-brokerage desk. Five stations, in order: content, seller origination, due diligence, CIM / listing, escrow.

## Content

The Content Engine runs on a rhythm. One idea or recorded session becomes the week's written work and the clips. The outline is approved before a draft exists.

## Seller origination

The call list refreshes from public signals: license years, review velocity, succession. The broker grades a ranked list: call, watch, succession already underway. Someone says yes. The file exists.

## Due diligence

Source pack lands: P&L, tax returns, lease, payroll. Due Diligence returns a provider map, add-backs only where the document supports them, red flags, and questions for the doctor. It doesn't invent a price. The broker decides if the file moves.

## CIM / listing

Verified numbers in. CIM, listing copy, and a branded PDF out — thesis, levers, marketing assets — from that sheet. Asking price and what buyers see under NDA stay with the broker.

## Escrow onboarding

The LOI is signed. Escrow onboarding pulls parties, price, earnest money, financing, and contingency dates. Four drafts: portal entry, escrow-open, buyer intro, seller intro. The transaction coordinator reads them. Then they go out.
