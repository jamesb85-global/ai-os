# Brokerage OS

Fulfillment engine for a practice-brokerage desk. Five stations. Canned Cedar Ridge run. Nothing uploads. A human still signs off at the end of every station.

Cedar Ridge Family Dentistry is invented sample data.

This folder is a rebuilt capability — method and skill shape — not a copy of any client instance.

| Station | Absorbs | Stays human |
|---|---|---|
| [Content Engine](cards/content-engine.md) | Written rhythm + webinar/clips | Point of view, outline approval, hook sign-off |
| [Seller Origination](cards/seller-origination.md) | Public signals → ranked call list | Who is actually HOT |
| [Due Diligence](cards/due-diligence.md) | Source docs → findings and flags | Whether the file advances. Never prices. |
| [CIM / Listing](cards/cim-listing.md) | Verified numbers → narratives + PDF | Asking price, what goes to buyers |
| [Escrow onboarding](cards/escrow-onboarding.md) | Signed LOI → kickoff pack | TC review before send |

Walk the canned traces in [traces.json](traces.json). Guardrails in [guardrails.md](guardrails.md). Station list in [stations.md](stations.md).

Do not demo Buyer Engine. It is not built.
